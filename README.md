# Student Management System

This is a simple Student Management System developed using C language.

## Features
- Add Student Record
- View Student Records
- Search Student by ID
- Delete Student Record
- File Handling

## Technologies Used
- C Programming
- Structures
- File Handling

## Files Included
- student.c
- students.txt
- OUTPUT.png

## How to Run

Compile the program:
gcc student.c -o student

Run the program:
./student

## Menu Options
1. Add Student
2. View Students
3. Search Student
4. Delete Student
5. Exit
